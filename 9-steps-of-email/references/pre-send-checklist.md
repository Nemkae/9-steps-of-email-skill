# 9 Steps of Email: Pre-Send Checklist

Working version used by the 9 Steps of Email skill. Canonical branded version: 9steps.email (checklist PDF). Items marked * are structural: an unconfirmed * item means hold the send. Everything else is the sender's call.

Rule IDs in brackets refer to `references/grading-rules.md`.

## 1. Point and purpose
- [ ] * The point of this email is stateable in one sentence without "and" [4.1]
- [ ] The email's content weight actually serves that point [4.2]
- [ ] The clear next action is identified, and it's one action [4.6]
- [ ] This send serves a declared goal of the channel [3.5]
- [ ] The recipient gets something from this email, stateable from their side [1.2, 3.5]

## 2. Conversion elements
Five questions, each answered with evidence from the email, not scored [4.3]:
- [ ] Relevance: within two seconds, it's clear who this is for and why now
- [ ] Offer value: what the reader gets is stated, not left to inference
- [ ] Incentive to act: there's a real reason to act now, not never
- [ ] Friction: every ask, link, and decision is spent on the point, not ornamentation
- [ ] Anxiety: what could make the reader hesitate at the click is addressed, not ignored

## 3. Landing page continuity [4.4]
- [ ] The destination's first screen continues the email's motivation, doesn't reset it
- [ ] The promised thing (offer, content, price) is present without hunting
- [ ] Incentives stated in the email survive to the page
- [ ] The page works on mobile for the action the email asked for

## 4. Structure and copy
- [ ] The primary message visibly dominates; supporting elements reinforce, don't compete [4.5]
- [ ] Voice matches the message type and the audience
- [ ] Personalization, if used, means something; fallbacks tested [5.3]
- [ ] Subject line makes a promise the body keeps [4.7]
- [ ] Subject line carries the point, not just a date [4.7]

## 5. Call to action
- [ ] * Primary CTA works with images blocked [4.6, 5.1]
- [ ] * Exactly one primary action, visually dominant, matching the point [4.6]
- [ ] CTA copy states action and outcome, not "click here" [4.6]
- [ ] Urgency, if present, is real [4.6]
- [ ] Tap-target size and placement work on mobile [4.6]

## 6. Rendering and mechanics
- [ ] * Every link tested and correct [5.3]
- [ ] * No unrendered placeholders or merge tags [5.3]
- [ ] Alt text on meaningful images [5.1]
- [ ] Checked on at least one mobile client [5.2]
- [ ] Readable font sizes and contrast; important content above the fold [5.1]
- [ ] Layout holds at 600-650px and collapses cleanly on mobile

## 7. Audience and sending
- [ ] The segment receiving this is the audience the point is for [4.8, 6.1]
- [ ] Engagement filter applied where the send is not transactional [6.3, 7.2]
- [ ] * Unsubscribe link present, visible, one click [2.1, 2.2]
- [ ] From address accepts replies (strongly advised, not required) [3.1 advisory]
- [ ] Send time chosen for the audience, and the system can honor it [Step 7]

**Verdict:** send / fix first / hold
